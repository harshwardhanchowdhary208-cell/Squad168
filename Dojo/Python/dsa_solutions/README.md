# DSA Solutions

Each file is a standalone Python solution for one readable Coding Workout challenge in the supplied PDF. Every program reads standard input and writes its result to standard output.

The PDF’s queue prompt is slightly inconsistent: it asks for an array-based custom queue but only supplies input for enqueueing values and then dequeuing all of them. `10_array_queue.py` follows that visible input/output behavior.

`20_remove_kth_node_from_end.py` follows the output format visibly requested in the prompt: `value -> value -> ... -> nullptr`.
