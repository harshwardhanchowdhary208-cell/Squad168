Lesson 4.08: Understanding State & useState Hook
1. What is State in React/Next.js?
State represents data that changes over time based on user interactions, network responses, or background processes.

Unlike standard variables, updating a state variable triggers React to re-render the UI component to reflect the latest values automatically.

2. Syntax & Usage
Import useState from React and declare it inside Client Components:

TypeScript
'use client';
import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState<number>(0);

  const increment = () => {
    setCount((prevCount) => prevCount + 1);
  };

  return (
    <button onClick={increment}>
      Count: {count}
    </button>
  );
}
3. Key Concepts
Client Components Only: Direct React hooks (useState, useEffect) can only be used in components marked with 'use client'.

Functional Updates: Use updater functions (e.g., setCount(prev => prev + 1)) when updating state based on the previous value to avoid stale closure issues.

State Immutability: Never mutate state directly (e.g., count = count + 1). Always use setter functions or create shallow copies for objects/arrays.

Lesson 4.09: Form Handling & Controlled Components
1. Controlled vs. Uncontrolled Components
Controlled Components: Form input values are driven directly by React state. The input value is bound to state, and updates are handled via onChange.

Uncontrolled Components: Form inputs maintain their own internal DOM state and are accessed using ref (via useRef).

2. Controlled Form Implementation
TypeScript
'use client';
import { useState, ChangeEvent, FormEvent } from 'react';

interface FormData {
  username: string;
  email: string;
}

export default function UserForm() {
  const [formData, setFormData] = useState<FormData>({
    username: '',
    email: '',
  });

  const handleChange = (e: ChangeEvent<HTMLInputElement>) => {
    const { name, value } = e.target;
    setFormData((prev) => ({ ...prev, [name]: value }));
  };

  const handleSubmit = (e: FormEvent) => {
    e.preventDefault();
    console.log('Form Submitted:', formData);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="text"
        name="username"
        value={formData.username}
        onChange={handleChange}
        placeholder="Username"
      />
      <input
        type="email"
        name="email"
        value={formData.email}
        onChange={handleChange}
        placeholder="Email"
      />
      <button type="submit">Submit</button>
    </form>
  );
}
Lesson 4.10: Data Fetching & Side Effects with useEffect
1. Role of useEffect
Manages asynchronous actions, subscriptions, DOM manipulations, or side-effects in Client Components.

Replaces class component lifecycle methods (componentDidMount, componentDidUpdate, componentWillUnmount).

2. Dependency Array Rules
No Array: Runs on every single render cycle.

Empty Array []: Runs once when the component mounts.

Array with Dependencies [dep1, dep2]: Runs on mount and whenever specified dependencies change.

3. Fetching Data in Client Components
TypeScript
'use client';
import { useState, useEffect } from 'react';

interface DataItem {
  id: number;
  title: string;
}

export default function DataFetcher() {
  const [data, setData] = useState<DataItem[]>([]);
  const [loading, setLoading] = useState<boolean>(true);

  useEffect(() => {
    async function fetchData() {
      try {
        const response = await fetch('/api/items');
        const result = await response.json();
        setData(result);
      } catch (error) {
        console.error('Error fetching data:', error);
      } finally {
        setLoading(false);
      }
    }

    fetchData();
  }, []);

  if (loading) return <p>Loading...</p>;

  return (
    <ul>
      {data.map((item) => (
        <li key={item.id}>{item.title}</li>
      ))}
    </ul>
  );
}
